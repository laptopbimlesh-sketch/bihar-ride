# Bihar Ride - "Apna Ride, Apna Bihar"
Native Android Kotlin + Jetpack Compose Application.
Application ID: com.biharride.app

How to open:
1. Open Android Studio Jellyfish or newer.
2. Select File > Open and pick this folder.
3. Configure your google-services.json and MAPS_API_KEY.
4. Run './gradlew assembleDebug' or './gradlew assembleRelease'.
